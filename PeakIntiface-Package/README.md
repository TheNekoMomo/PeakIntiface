# PEAK Intiface

Connects PEAK gameplay events to Intiface/Buttplug compatible devices.

## Requirements

- PEAK
- BepInEx
- Intiface Central
- A Buttplug compatible device

## Setup

1. Install the mod.
2. Start Intiface Central.
3. Start the Intiface server.
4. Launch PEAK.
5. Configure the Intiface IP and port in the mod settings.

Default server:

- IP: `127.0.0.1`
- Port: `12345`

## Current triggers

- Normal climbing
- Rope climbing
- Vine climbing
- Sprinting
- Status effects
